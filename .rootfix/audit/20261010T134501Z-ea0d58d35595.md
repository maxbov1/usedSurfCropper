## Request

Implement constrained board grouping for the UsedSurf photo pipeline. Inventory-card count should establish the expected number of boards, but code must not force visually incompatible photos or cards into groups merely to satisfy that count. Board similarity should create contiguous visual runs, card matching should be one-to-one and confidence-gated, and unmatched photos/cards must remain visible for review. Explicit per-photo identity evidence such as brand, model, fin system, or fins-included is optional when absent, but a detected value must not be contradicted by assignment to a card with a different value; unresolved contradictions must remain visible for review.
